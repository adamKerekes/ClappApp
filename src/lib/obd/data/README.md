# OBDb Peugeot 508 jelkészlet

Az `obdb-peugeot-508.json` az [OBDb/Peugeot-508](https://github.com/OBDb/Peugeot-508) `signalsets/v3/default.json` fájljából készült a `scripts/import-obdb.js` szkripttel (csak tömörítve, a tartalom változatlan).

Licenc: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), szerzők: az OBDb közreműködői. Ez a fájl ugyanezen licenc alatt áll.

Frissítés:

```bash
git clone --depth 1 https://github.com/OBDb/Peugeot-508.git /tmp/Peugeot-508
node scripts/import-obdb.js /tmp/Peugeot-508/signalsets/v3/default.json
```
